## 📚 Week 4 — Frames and Links

Programs demonstrating HTML frames and navigation between pages.

### Main concepts

* Framesets
* Multiple frames
* Navigation menus
* `target` attribute
* Linking multiple HTML pages

### Files

```text
index.html
menu.html
home.html
about.html
contact.html
```

The `index.html` file creates two frames:

* **25%** — Menu
* **75%** — Content

The menu links load pages inside the content frame.
